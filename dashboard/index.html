Which protocol launches next — and what would its token be worth?

Every protocol the snapshot records with no token, ranked by an implied value built only from its own figures: its TVL, its seven-day growth, how long it has run with no token, and how many chains it spans.

How the number is made

implied = 100 × TVL0.7 × (1 + 0.35 × growth) × maturity × breadth × plausibility

  • Size: TVL to the power 0.7 — log-scaled, so ten times the TVL is about five times the value.
  • Growth: seven-day TVL change, clamped to −50% … +300%, weighted 0.35.
  • Maturity: 0.70 → 1.00 over 1,500 days since first listed; 0.85 when the listing date is unknown.
  • Breadth: +2% per extra chain, up to five.
  • Plausibility: 0.05 for exchanges and for products that wrap, stake or bridge a token that already trades — their token, if any, already exists in another form. Everything else scores 1.00.

A protocol here records no token; that is not proof it has none. Implied values are this entry’s own claim, never a prediction of whether or when a token is issued. Equal formula values are separated by one dollar so the ranking is strict.
